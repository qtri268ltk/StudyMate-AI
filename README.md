# StudyMate-AI
Trợ lý Đọc hiểu, Tóm tắt và Khảo thí thông minh

1. Giới thiệu StudyMate AI
**StudyMate AI** là một ứng dụng được thiết kế nhằm hỗ trợ người học đọc hiểu tài liệu và ôn luyện kiến thức hiệu quả[cite: 2]. Ứng dụng ứng dụng công nghệ AI (dựa trên cơ chế RAG) với các chức năng nổi bật sau:
* Tải lên các tài liệu học tập dưới định dạng PDF.
* Tự động tạo bản tóm tắt cốt lõi từ tài liệu gốc.
* Hỗ trợ hỏi đáp thông tin trực tiếp dựa trên nội dung tài liệu.
* Tự động sinh câu hỏi trắc nghiệm và câu hỏi ôn tập để người dùng tự kiểm tra kiến thức.

2. Hướng dẫn chạy thử nghiệm (Test)
Để trải nghiệm và kiểm thử các tính năng của ứng dụng trên máy cá nhân, bạn có thể làm theo các bước dưới đây:
* **Bước 1: Tải mã nguồn**
  Tải source code của dự án StudyMate AI về máy tính.
* **Bước 2: Lấy API Key**
  Truy cập vào Google AI Studio, đăng nhập và tạo một API key mới.
* **Bước 3: Khởi chạy và trải nghiệm**
  Mở file source code (prototypeV2.html) bằng trình duyệt web hoặc khởi chạy server cục bộ (localhost) và dán API key vừa lấy được vào. Sau đó, bạn có thể bắt đầu tải tài liệu PDF lên và test các chức năng tóm tắt, hỏi đáp.
